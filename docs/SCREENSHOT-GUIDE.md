## How to Capture Screenshots

### Option 1: Browser Screenshots (Recommended)
1. Navigate to each `/demo/[page]` route in your browser
2. Use browser screenshot tools:
   - **Chrome/Edge**: Press `Ctrl+Shift+P` (Windows) or `Cmd+Shift+P` (Mac), type "screenshot", select "Capture full size screenshot"
   - **Firefox**: Press `Ctrl+Shift+S` (Windows) or `Cmd+Shift+S` (Mac)
   - **Safari**: Use `Cmd+Shift+5` for screenshot tools

### Option 2: OS Screenshot Tools
- **Windows**: Windows + Shift + S (Snipping Tool)
- **Mac**: Cmd + Shift + 4 (Select area) or Cmd + Shift + 5 (Screenshot toolbar)
- **Linux**: Various tools (Flameshot, GNOME Screenshot, etc.)

### Option 3: Browser Extensions
- Awesome Screenshot
- Nimbus Screenshot
- GoFullPage (for full-page captures)
